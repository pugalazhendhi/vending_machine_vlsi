Vending Machine Using Verilog HDL

Project Overview

Designed and implemented a digital vending machine using Verilog HDL in Xilinx Vivado. The project simulates the operation of an automated vending machine that allows users to select products by providing the required inputs. The system processes the selection, checks the inserted amount, and controls the product dispensing operation based on the input conditions.

Objectives

- To design a digital vending machine using Verilog HDL.
- To understand Finite State Machine (FSM) concepts.
- To implement product selection and payment processing logic.
- To simulate and verify the functionality using Vivado.

Tools and Technologies

- HDL: Verilog
- Software: Xilinx Vivado
- Design Concept: Finite State Machine (FSM)
- Verification: Verilog Testbench and Simulation

Key Features

- Multiple product selection.
- Payment input processing.
- Amount verification.
- Product dispensing control.
- Sequential logic-based operation.

Implementation

The vending machine was designed using Verilog HDL and implemented in Xilinx Vivado. The design was simulated using a testbench to verify the functionality of the system under different input conditions.

Learning Outcomes

- Practical understanding of Verilog HDL.
- Knowledge of FSM-based digital system design.
- Experience with RTL design and simulation.
- Hands-on experience with Xilinx Vivado.
